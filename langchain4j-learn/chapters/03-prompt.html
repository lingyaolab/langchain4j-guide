03 · Prompt 与消息：模板、变量与多模态

SystemMessage / UserMessage / AiMessage / ToolExecutionResultMessage、PromptTemplate、变量注入与图片输入。

读完你能做到

  • 用消息类型而不是一坨字符串表达提示词
  • 用 PromptTemplate 管理变量
  • 把图片或文件作为 Content 放进用户消息
  • 知道模板变量缺失时会发生什么

先说为什么：提示词是消息列表，不是字符串

模型接口最终接收的是 List<ChatMessage>。字符串只是 UserMessage.from(text) 的快捷方式；一旦要做多轮、工具或图片，就必须回到消息层。

四种消息：System / User / AI / Tool

类型谁产生用途
SystemMessage应用角色、边界、输出格式
UserMessage用户 / 应用本轮问题，可带文本与图片
AiMessage模型回答或工具调用请求
ToolExecutionResultMessage框架工具执行结果，回填给模型

SystemMessage.java:24 UserMessage.java:39 AiMessage.java:32

PromptTemplate：变量、默认值与转义

PromptTemplate template = PromptTemplate.from("""
        你是{{role}}。请用不超过 {{maxWords}} 字回答：
        {{question}}
        """);

Prompt prompt = template.apply(Map.of(
        "role", "Java 架构师",
        "maxWords", 120,
        "question", "什么时候该把 RAG 拆成独立服务？"));

String text = model.chat(prompt.toUserMessage().singleText());

PromptTemplate.from(...) 支持命名变量；apply(Map) 会把变量填进去。 变量缺失时会在渲染阶段抛异常，而不是静默留空。

模板入口 PromptTemplate.java:152； 渲染 PromptTemplate.java:127。

模板变量与运行时参数

「模板变量」是提示词里的 {{name}}；「运行时参数」是 temperature、maxOutputTokens 这些模型参数。两者不要混在一个 Map 里： 前者进 PromptTemplate.apply，后者进 ChatRequestParameters。

多模态：文本、图片与文件

UserMessage message = UserMessage.from(
        TextContent.from("这张架构图里，哪个组件最可能成为瓶颈？"),
        ImageContent.from("https://example.com/arch.png"));

ChatResponse response = model.chat(message);

图片是否被支持取决于 provider 与模型；不支持时通常会在 HTTP 层报参数错误。 ImageContent.from(...) 可以接收 URL 或 base64。

陷阱与窍门

把 JSON 示例直接写进系统提示词

花括号可能被模板引擎当成变量；用 { / } 转义，或改用代码块。

以为 SystemMessage 一定生效

部分模型/网关会忽略 system 角色；关键约束要在用户消息里再强调一次。
