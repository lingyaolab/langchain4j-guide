把 LangChain4j 1.23.0 学到「能自己接进项目」

这不是官方文档的搬运，而是一套按工程落地顺序重排、每个结论都能回源码验证的教程。默认用 OpenAI 兼容端点接 DeepSeek；需要本地跑就把 baseUrl 换成 Ollama。示例全部是 JDK 17 + Maven，每一章都有能复制运行的代码、一次调用的完整链路，以及「你会撞到什么错」。

    它会告诉你三条主线怎么用、章节为什么是这个顺序、以及没有 API Key 能学到哪一步。

    → 02 ChatModel：从 OpenAiChatModel.builder() 到 chat()、ChatRequest 与流式输出。

三条学习主线

① 跟做线：照抄能跑

  • 每章「最小可跑」都是完整工程结构，含 pom.xml 与配置
  • 代码里出现的每个 API 都能在附录 C 的速查表里查到出处
  • 目标是「先跑起来」，不追求先看懂

② 理解线：知道它在干什么

  • 每章「端到端」把一次调用拆成接口、消息、请求与响应四段
  • 关键机制给分层图：谁调谁、参数在哪生效、失败在哪一层

③ 避坑线：出错时知道看哪儿

  • 每章「陷阱与窍门」按「你会看到 X → 因为 Y → 改成 Z」写
  • 重点标出 0.x 到 1.x 的 API 变化，以及 1.23.0 的稳定/beta 双版本

事实来源与版本承诺

本站内容严格对应 LangChain4j 1.23.0 与 JDK 17，写作时逐条回源核对， 来源只有三类：

类型 路径 用来确认什么
Java 源码 langchain4j-core/、langchain4j/、langchain4j-open-ai/ 方法签名、默认值、抛错点、判定分支
BOM 与模块 langchain4j-bom/pom.xml、各模块 pom.xml 稳定/beta 版本、artifactId、传递依赖
官方文档源 docs/docs/ 设计意图、能力边界、术语原文

页面上所有 文件名:行号 形的胶囊都是出处标签：单击复制完整路径，Ctrl/Cmd + 点击在 GitHub 上打开对应文件。

已知边界
  • LangChain4j 的稳定模块与 beta 模块共用一套仓库，但版本号不同：BOM 是 1.23.0， 部分实验模块是 1.23.0-beta33。正文默认只讲稳定模块。
  • 默认示例使用 OpenAI 兼容协议（DeepSeek / Ollama），不绑定某一家厂商；换 provider 只换依赖和构造器。
  • 进度与主题只保存在本机浏览器 localStorage，不会上传任何数据。
