A · 术语表：中英对照 + 一句话直觉

ChatModel、AI Service、Embedding、Retriever、Tool、Memory 等核心术语。

对话与模型

术语一句话
ChatModel同步对话接口，输入消息、输出 ChatResponse。
StreamingChatModel流式对话接口，通过回调逐块返回。
ChatRequest把消息与参数装在一起的一次请求。
ChatResponse模型响应，含 AI 消息、token 用量与元数据。
AI Service用 Java 接口描述 AI 能力，由框架动态实现。
ChatMemory决定本轮带哪些历史消息；持久化交给 ChatMemoryStore。

RAG 与检索

术语一句话
Document加载后的原文与 metadata。
TextSegment切分后的文本块，带 metadata 与向量。
Embedding文本的向量表示。
EmbeddingStore保存向量并支持相似度检索。
ContentRetriever给一个问题，返回若干相关内容。
RetrievalAugmentor把召回内容拼进提示词的组件。

工具与 Agent

术语一句话
@Tool把 Java 方法暴露给模型调用。
InvocationContext本次调用的上下文，工具可读取用户/会话信息。
ToolExecutionResult工具结果，可标记成功或失败。
MCPModel Context Protocol，用标准协议暴露工具与资源。
Agent带工具循环、记忆与规划能力的模型应用。
