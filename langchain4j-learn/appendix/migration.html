BOM 版本是 1.23.0，稳定模块跟 BOM 走；实验模块是 1.23.0-beta33。引入实验模块时，BOM 已替你写好 beta 版本， 不要手动把稳定模块也改成 beta。

API 变化

  • 0.x 的 ChatLanguageModel 在 1.x 中统一为 ChatModel。
  • 工具上下文统一为 InvocationContext（1.6+）与 ToolExecutionResult。
  • 结构化输出由 AI Service 返回类型驱动，少写手拼 JSON 的提示词。
  • RAG 统一到 ContentRetriever 与 RetrievalAugmentor。
